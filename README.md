# PROJET BI - ANALYSE DES VENTES
# Objectif du projet
L’objectif de ce projet est d’analyser les données de ventes afin de suivre l’évolution du chiffre d’affaires, du nombre de ventes et du panier moyen.
Le projet permet également d’identifier les principales tendances commerciales selon les années, les catégories de produits, les produits, les villes et les clients.
Les résultats sont présentés dans un dashboard interactif réalisé avec Power BI afin de faciliter l’analyse et l’interprétation des données.

# Le cycle du projet
1. Collecte des données : fichiers CSV contenant les clients, produits et ventes
2. Importation dans PostgreSQL : création des tables et vérification de l'intégrité des données
3. Analyse SQL : exploration des ventes et calcul des principaux indicateurs
4. Power Query : connexion aux données et préparation dans Power BI
5. Modélisation : création des relations entre clients, produits et ventes
6. DAX : création des mesures et KPI
7. Power BI : création du dashboard interactif
8. Analyse business : interprétation des résultats et identification des principaux constats

# Technologies utilisées
. PostgreSQL : stockage et analyse initiale des données
. SQL :  exploration et analyses commerciales
. Power Query : préparation et transformation des données
. Power BI : création du modèle et du dashboard
. DAX : création des mesures et KPI
. GitHub : versionnement et documentation du projet
